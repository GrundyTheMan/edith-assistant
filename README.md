# Edith

A personal-assistant app. She chats (streaming), uses tools (weather, web, calendar, mail), takes voice memos and attachments, controls a smart home and a 3D printer, and speaks her replies. Her "brain" is a local [Ollama](https://ollama.com) server on the owner's PC.

- `app/`: the Android app (Kotlin, Jetpack Compose).
- `ios-app/`: the iPhone app (Expo / React Native, TypeScript).
- `docs/design/`: the complete design, split into chunks, with the decisions and what is built.
- `AGENTS.md`: how the project is built, tested and run (written for AI coding agents, readable by people).

This is a personal project, published so it can be built in the cloud for free. It is not a product, takes no support requests, and **no license has been chosen yet**: until one is added, all rights are reserved.
